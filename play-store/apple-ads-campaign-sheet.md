# Apple Ads — Open Season campaign sheet

Paste-ready setup for ads.apple.com (Advanced). One campaign, four ad
groups, ~$200/month. Built 2026-09-15; keywords rotate seasonally (see
bottom).

## Campaign

| Setting | Value |
|---|---|
| Name | Open Season — US |
| App | Open Season: Dates & Draws |
| Countries | United States |
| Daily budget | $7.00 |
| CPA goal | leave blank |
| Devices | iPhone and iPad |
| Ad scheduling | all day |
| Audience | everyone (no demographic narrowing) |

## Watch weekly

- Cost per install under ~$2; pause exact keywords with 25+ taps and no installs.
- Trial starts (RevenueCat) are the real KPI, not taps.
- Discovery search-terms report → promote winners to Category exact.

## Seasonal rotation

- Jan–Jun: swap state-season keywords for draw terms — elk draw, wyoming
  elk draw, colorado draw deadline, tag application deadline, spring
  turkey season.
